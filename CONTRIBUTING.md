# Contributing to public NodeMCP documentation

Thanks for helping make the NodeMCP documentation more useful.

This is a **documentation and integration-example repository**, not a distribution of the proprietary gateway or agent source code.

For a documentation edit:

1. Open a documentation issue explaining the problem and the URL or document involved.
2. Propose clear wording and include the device OS/client version only if doing so does not expose private information.
3. Submit a focused pull request with a short summary and links to the corrected reference material.

Do not submit private logs, customer files, API tokens, pairing codes, passwords or device IDs. Please avoid speculative feature claims or promises of universal compatibility. Important behavior changes should be verified against current official [documentation](https://nodemcp.dev/docs/).

By contributing you agree that your contribution may be published as documentation; contact the maintainers about any rights or licensing questions before including third-party text or images.
