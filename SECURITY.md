# Security Policy

## Reporting a vulnerability

**Do not disclose exploitable details, tokens, customer data or private server information in a public GitHub Issue.**

For a potential NodeMCP security problem, contact **manager@nodemcp.dev** privately with a concise summary, affected component, reproduction conditions and a safe way to coordinate further details. Never include live credentials in an initial message.

If an account or device access may be compromised, revoke the affected authorizations in the NodeMCP Control Center immediately; do not wait for a reply.

## Scope

The NodeMCP remote gateway and commercial agents are hosted/distributed separately and are **not** published as open-source code in this documentation repository. For supported platforms, permissions and current product behavior, read [security documentation](https://nodemcp.dev/docs/security-model/) and [terms](https://nodemcp.dev/terms-of-service/).

We welcome responsible reports. This document does not grant permission to test infrastructure or devices belonging to other users.
